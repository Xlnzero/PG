## ⚠️ Что нужно сделать на сервере

### 1. Создать .env файл

Скопируйте `.env.example` в `.env` и заполните реальными значениями:

```env
DJANGO_SECRET_KEY=ваш-секретный-ключ-здесь
DEBUG=False
ALLOWED_HOSTS=your-domain.com,www.your-domain.com
EMAIL_HOST_USER=your-email@mail.ru
EMAIL_HOST_PASSWORD=your-email-password
```

**ВАЖНО:**
- Генерируйте новый SECRET_KEY для production (не используйте ключ из разработки!)
- Укажите реальный домен в ALLOWED_HOSTS
- Убедитесь, что DEBUG=False

### 2. Генерация SECRET_KEY

Выполните на сервере:
```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Проверка пути в passenger_wsgi.py

Убедитесь, что путь в `passenger_wsgi.py` соответствует реальному пути на сервере:
```python
project_dir = '/home/pangranby/pangran'  # Проверьте этот путь!
```

### 5. Сборка статических файлов

```bash
python manage.py collectstatic --noinput
```

### 6. Миграции базы данных

```bash
python manage.py migrate
```

## 🐛 Возможные проблемы

### Проблема: "DJANGO_SECRET_KEY не установлен"
**Решение:** Создайте .env файл и установите SECRET_KEY

### Проблема: "ALLOWED_HOSTS не установлен"
**Решение:** Добавьте ALLOWED_HOSTS в .env файл с вашим доменом

### Проблема: Почта не отправляется
**Решение:** 
1. Проверьте EMAIL_HOST_USER и EMAIL_HOST_PASSWORD
2. Убедитесь, что на mail.ru включен SMTP
3. Возможно, нужен пароль приложения, а не обычный пароль

### Проблема: Статические файлы не загружаются
**Решение:**
1. Выполните `python manage.py collectstatic`
2. Проверьте права доступа к папке staticfiles
3. Проверьте настройки веб-сервера для обслуживания статических файлов
